# Параметры запуска 3D-превью

3D-превью — `src/game3d/level3d_preview.tscn`, главная сцена проекта (её же
открывают F5 и сборка). Параметры превью пишутся после `--`, параметры самого
Godot — до него:

```bash
godot --path . src/game3d/level3d_preview.tscn -- --players 2 --boss
```

Подробные комментарии к каждому — в шапке `src/game3d/level3d_preview.gd`.

## Игра

| Параметр | Что делает |
|---|---|
| *(без параметров)* | Экран заголовка (`level3d_title.gd`): 1 или 2 игрока, сложность, настройки, выход. Заставка — Chinook (`level3d_splash_landing.gd`): прилетает из-за камеры и садится перед солнцем; по выбору игры джипы сразу разворачиваются и заезжают в него по рампе (если он ещё не сел — ждут у места посадки), а взлетает он, только когда уровень под заставкой загружен; тогда экран гаснет. Любая клавиша во время погрузки сразу переходит к затемнению. Игра начинается с прилёта «Чинука» |
| `--splash-3d` | Вместо Chinook — прототип 3D-заставки, из которого она выросла (`level3d_splash3d.gd`): только джипы в cel-shading против солнца |
| `--splash-picture` | Вместо 3D-заставки — первая, картинка с закатом (`level3d_splash.gd`) |
| `--splash-dust` | С 3D-заставкой: облака пыли, которые ветер гонит по земле. По умолчанию выключены |
| `--splash-landing` | Ничего не меняет: так включали заставку с Chinook, пока она не стала основной |
| `--splash-puffs` | С 3D-заставкой: пыль (из-под колёс, от винтов Chinook, от ветра) — отдельные мультяшные клубы из круглых лепестков, каждый на своей карточке, а не одно облако с обводкой на источник, как по умолчанию (`level3d_cel_cloud.gd`) |
| `--splash-motes` | То же, но пыль — мягкие полупрозрачные частицы, без контура |
| `--splash-veil` | С заставкой с Chinook: тонкая мягкая дымка, которую винты Chinook гонят от корпуса по земле, под облаками пыли. По умолчанию выключена |
| `--players 2` | Кооператив на двоих: второй, синий джип на стрелках, правом Alt (пулемёт) и правом Ctrl (ракета) |
| `--intro` | Без экрана заголовка, сразу прилёт «Чинука». Со `--shot`: снимок отсчитывается от прилёта |
| `--landing-dust` | Пыль от винтов «Чинука» при посадке и взлёте: одно облако с обводкой, стелется по земле от краёв корпуса (`level3d_wash.gd`). По умолчанию выключена |
| `--no-chinook` | Пропустить выгрузку с «Чинука», как пробел в игре: джип сразу на земле |
| `--boss` | Начать в 48 рядах карты ниже триггера босса, в нескольких секундах езды до арены. Солдаты, танки и лодки на пройденном пути не появляются; выгрузки с «Чинука» нет |
| `--btr` | БТР вместо джипа |
| `--immortal` | Пули врагов проходят насквозь (как чит Bullet hack); таран пушки или танка по-прежнему убивает |
| `--fade-corpses` | Убитые солдаты исчезают, как в игре; по умолчанию лежат |

`--no-chinook` и `--boss` действуют на каждый старт забега: первый, игру с
экрана заголовка и перезапуск клавишей R. Сложность (normal/hard) выбирается
на экране заголовка и сохраняется в настройках, флага у неё нет.

Настройки игрока (меню по Escape) хранятся в `user://preview3d.cfg`. Флаги
`--shot` и `--obstacle-map` их не читают и не сохраняют.

## Другой уровень

| Параметр | Что делает |
|---|---|
| `--file <res://…json>` | Играть другой файл уровня вместо `assets/level3d/stage-0.json` — сделанный в редакторе уровней |
| `--level <res://…glb>` | Его собранная модель вместо `resources/3d/jackal_stage1.glb` (`tools/blender/build_level.py`) |
| `--editor` | Так запускает Play в редакторе уровней: без экрана заголовка, выход из меню называется «Back to the editor» |

## Снимок кадра

Отрисовать кадр в файл и выйти. Нужно настоящее окно: у `--headless` нет
кадрового буфера.

```bash
godot --path . --windowed --resolution 1280x720 src/game3d/level3d_preview.tscn -- --shot out.png 0.5 1 top 8
```

`--shot <файл> <позиция> <зум> <top|tilt> [<секунды> <x,z> …]`

- **позиция** — доля уровня от 0 (старт) до 1 (конец) или точка `x,z` в метрах
  (z вверх по уровню отрицательный);
- **зум** — 1 показывает уровень во всю ширину;
- **top** — вид сверху, как в игре; **tilt** — наклонная камера;
- **секунды** — снять кадр через столько секунд; следующие за ними `x,z` —
  точки маршрута, по которым едет машина.

Снимок стартует без «Чинука» и с классической стрельбой и печатает в консоль,
что делают враги. К нему добавляются:

| Параметр | Что делает |
|---|---|
| `--at <x,z>` | Поставить машину сюда вместо старта |
| `--free` | Свободная езда: газ и руль |
| `--hold <клавиши>@<от>-<до>,…` | Держать W/A/S/D/L/P в эти секунды, например `wd@0-1.5,l@2-3`; с `2:` — второй игрок (`2:s@0-3`) |
| `--fire <x,z>` | Стрелять из пулемёта в точку с самого начала |
| `--rocket <x,z>[@<сек>]` | Пустить ракету в точку, сразу или через столько секунд |
| `--destroy <имя>,…` | Взорвать здания на старте (имена — id их объектов в файле уровня: `Barracks`, `Hangar_E`, `Gate`…) |
| `--weapon <0–3>` | Оружие: 0 граната, 1–3 ракета и два её улучшения |
| `--pows <n>` | Столько пленных на борту у каждого игрока |
| `--score <n>` | Начальный счёт — он же деньги магазина; жизней очки больше не дают |
| `--round <n>` | Начинать каждый забег (и по R, и с титула) с этого круга этапа; со второго — враги из списка hard |
| `--hold k@<от>-<до>` | Как другие клавиши `--hold`: держать клавишу устройства (нитро, мины, авиаудар) |
| `--shop` | Сразу открыть магазин между кругами поверх этапа, как после победы над боссом |
| `--log-rounds` | В консоль: сколько каждый игрок заработал за круг и с чем вышел из магазина — для подгонки цен |
| `--upgrades <id>,...` | Каждый игрок начинает каждый забег с этими апгрейдами магазина (`twin`, `armor`, `zip`, `nitro`, `radar`, `mines`, `loopholes`, `airstrike`); их детали видны на джипе |
| `--summary <сек>` | Показать итог миссии через столько секунд, как после победы над боссом |
| `--game-over <n>[,<n>][:<всего>]` | Без экрана заголовка сразу открыть экран конца игры (`level3d_game_over_screen.gd`: кладбище, GAME OVER, счёт, CONTINUE / END): столько спасённых у первого игрока (и у второго), столько пленных было всего (по умолчанию — сколько их на этапе). Быстрее без этапа: `tools/game_over_shot.gd` |
| `--no-rain` | Сцена конца игры без дождя: закат, под которым она сделана, вместо пасмурного вечера |
| `--lives <n>` | Столько запасных жизней у каждого игрока; `--lives 0 --die 1` доводит до конца игры, как в игре: баннер GAME OVER, затемнение, кладбище |
| `--die <сек>` | Взорвать машину через столько секунд — для обломков |
| `--strip <кадры>,<сек>[,<px>]` | Серия кадров с интервалом, центральные квадраты по 4 в ряд в одном файле — например, взрыв целиком |

Параметры игры (`--players`, `--btr`, `--immortal`, `--boss`, `--intro` и
т. д.) работают и со снимком.

## Карта столкновений

```bash
godot --path . --headless src/game3d/level3d_preview.tscn -- --obstacle-map out.png
```

Рисует столкновения уровня картинкой (земля, вода, лес, стены) и выходит —
проверка `_add_collision`. Работает без окна.

## Графика

| Параметр | Что делает |
|---|---|
| `--light <day\|golden\|dusk\|sunrise>` | Освещение уровня (`level3d_lighting.gd`): день, как в Blender (по умолчанию), золотой час, закат или рассвет в палитре заставки. В игре — Graphics → Light, сохраняется в настройках; флаг важнее настройки и работает со `--shot` |
| `--no-wind` | Пальмы и деревья неподвижны |
| `--wind-steps` | Качание деревьев рывками, 8 поз в секунду; в игре переключает G |
| `--spots` | Ракеты и бомба миномёта отбрасывают пятно на землю вместо настоящей тени; в игре переключает H |
| `--no-contour` | Без контурных линий у моделей |
| `--baked-contour` | Контур, запечённый в glb, вместо движкового — для сравнения |
| `--engine-creases` | Прототип: движок рисует линии и по острым рёбрам |
| `--btr-noline` | Прототип: БТР без фасок, для `--engine-creases` |

Параметр Godot, до `--`: `--rendering-method forward_plus` — свет ближе к
рендеру Blender; проект по умолчанию рендерит в Compatibility.

## Отладка

| Параметр | Что делает |
|---|---|
| `--audio-debug` | Раз в секунду печатать по каждой звуковой шине: выключена ли, громкость, пик |

Если звука нет совсем, `tools/audio_check.ps1` покажет, что с ним делает
Windows: устройство вывода, громкость, выключенные в микшере программы.
